# loomy-cli

Mac CLI for the Loomy build/agent infra. Talks to loomy-server through the public tunnel.

```
loomy init                # bootstrap auth
loomy ping                # confirm reach
loomy chat "..."          # streamed chat with hermes
loomy install --skill loomy-basics
```

See `~/ifly/loomy-design/docs/plans/2026-05-09-loomy-cli-design.md` for the v1 design.
